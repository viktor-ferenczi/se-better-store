Better Store, approved design

Drawn to scale inside a 16:9 game window, at the size of the game's terminal screen (it also fits 4:3), using only controls the game's GUI has. Clickable: example ships, stock and prices; Buy and Sell change the example cargo.

Balance

What the game's GUI allows, and what changed from round 1

  • Built from the game's own controls: a table, a combo box, progress bars, a text box, plain rectangular buttons, labels, list boxes. Square corners, one font, the game's blue-grey skin.
  • A table cell holds one text and one icon, nothing else. So no "Sell all" button in each row and no coloured tags: lots show in the price text ("1 /kg · 1,020 /t"), or as "Stone (1 t lot)" with separate rows.
  • Sell all is the button next to Sell for the selected item; Sell all cargo sits under the table. Double-click on a row trades the amount in the box, as in the vanilla screen.
  • Preset chips became one row of six small buttons. The amount box takes typed input ("2500", "2.5t").
  • The table shows 15 rows before it scrolls; "Goes into" shows 3 containers and scrolls for more.
  • Results go to the status line at the bottom right; refusals from the server use the game's message box, as today.
  • The green part of the Cargo and Hydrogen bars previews the trade. That is a second bar drawn over the first, which the game can do.

Decided

  • Lots: merged into their item by default; the checkbox lists them as separate rows, and the plugin remembers it.
  • Which rows are lots: Octahedron sends the plugin its lot list when a Store opens. On other servers the plugin guesses from the price ratio of two rows of one item.
  • Vanilla screen: replaced. Administration opens the game's own screen for Store owners; turning the plugin off brings vanilla back.
  • Sell all cargo: kept, and it always asks once with the item count and total. Single-item trades never ask.
  • H2/O2 orders: hidden on the Sell tab. Mod-API Gas orders show and drain the ship's tanks.
